# SOLOLINGO 🦉 — AI 홈트레이닝

> 폰 카메라로 운동 자세를 인식해 **횟수를 자동으로 세어 주는** 홈트레이닝 웹앱
> 설치 없이 브라우저에서 바로 쓰고, 홈 화면에 추가하면 앱처럼 실행됩니다 (PWA).

**▶ 바로 사용하기: https://hvnwxu.github.io/sololingo/**

---

## 주요 기능

| 기능 | 설명 |
|---|---|
| 📷 AI 자세 인식 | 카메라 영상에서 관절 위치를 찾아 스쿼트·런지·푸쉬업 횟수와 플랭크 유지 시간을 자동으로 셉니다 |
| 🗺️ 단계형 코스 | 스쿼트 → 런지 → 푸쉬업 → 플랭크 → 버피테스트 순서로 하나씩 열리는 학습 경로 |
| 🎯 목표·난이도 | 다이어트 / 몸 만들기 / 바디프로필 × 초급 / 중급 / 고급에 따라 세트·횟수·휴식 시간이 달라짐 |
| ⏱️ 세트 & 휴식 | 세트가 끝나면 휴식 타이머가 자동으로 시작되고 음성으로 안내 |
| 📱 폰 위치 안내 | 운동별로 폰을 어디에, 어떤 방향으로 둬야 인식이 잘 되는지 그림으로 안내 |
| ⭐ 게임 요소 | XP·레벨, 일일 퀘스트, 업적 배지 5종, 연속 운동 일수 |
| 🥗 식단 가이드 | 운동 5개를 모두 끝내면 목표별 식단 예시가 열림 |
| 📋 기록 복사 | 운동 기록을 텍스트로 정리해 클립보드에 복사 (AI 인식 완료 / 수동 완료 구분) |

## 사용 방법

1. 폰 브라우저(크롬·사파리)에서 위 링크를 엽니다. 카메라 권한을 허용합니다.
2. 상단에서 **운동 목표**와 **난이도**를 고릅니다.
3. 열려 있는 단계(처음엔 ① 스쿼트)를 누르고, 안내에 따라 폰을 세운 뒤 **준비 완료! 시작하기**를 누릅니다.
4. 화면 안에서 운동하면 횟수가 자동으로 올라갑니다.
   인식이 어려운 환경이라면 **수동 완료**도 가능합니다 (AI 인식 완료와 별도로 기록).
5. 홈 화면에 추가하기: 안드로이드 크롬은 **📲 앱 설치** 버튼, 아이폰 사파리는 공유 → **홈 화면에 추가**.

## 동작 원리

```
카메라 영상 ──▶ MediaPipe Pose (관절 33개 좌표) ──▶ 각도·길이 계산 ──▶ 상태 판정(UP/DOWN) ──▶ 횟수 +1
```

- **관절 인식**: Google의 [MediaPipe Pose](https://developers.google.com/mediapipe) 모델이 프레임마다 어깨·팔꿈치·엉덩이·무릎·발목 등의 위치와 신뢰도(visibility)를 알려 줍니다.
- **더 잘 보이는 쪽 선택**: 왼쪽/오른쪽 관절의 신뢰도를 비교해 카메라에 더 잘 보이는 쪽 몸을 사용합니다.
- **운동별 판정**
  - **스쿼트·런지**: 엉덩이~무릎 세로 길이(허벅지)를 몸통 길이로 나눈 비율을 씁니다. 서 있을 때 값과 비교해 앉았는지 판단하고, 발목이 보이면 무릎 각도(엉덩이-무릎-발목)도 함께 봅니다. 몸통 길이로 나누기 때문에 카메라와의 거리가 바뀌어도 기준이 유지되고, 정면·측면 모두 인식됩니다.
  - **푸쉬업**: 팔꿈치 각도(어깨-팔꿈치-손목)가 100° 아래로 내려갔다가 145° 위로 올라오면 1회.
  - **플랭크**: 어깨-엉덩이-무릎(발목)이 일직선인지 확인합니다. 1초 넘게 자세가 무너졌을 때만 타이머를 멈춰서, 잠깐 흔들린 건 봐줍니다.
- **흔들림 줄이기**: 한 프레임만 튀는 값에 속지 않도록 최근 값과 섞는 평균(지수 이동 평균)을 씁니다. 신뢰도 0.5 미만인 관절은 "안 보임"으로 처리합니다.
- **두 번 세기 방지**: `UP → DOWN → UP` 순서를 거쳐야만 1회로 셉니다.
- **오류 대응**: 인식 중 오류가 나면 더 가벼운 모델로 바꿔 최대 3번 다시 시도합니다.

## 개인정보

- **카메라 영상은 폰 안에서만 처리되며 어디에도 전송되지 않습니다.** 서버가 없습니다.
- 운동 기록은 브라우저의 `localStorage`에만 저장됩니다. 그래서 다른 기기나 브라우저에서는 기록이 보이지 않습니다.

## 기술 스택

| 구분 | 사용 기술 |
|---|---|
| 화면 | HTML, CSS, JavaScript (프레임워크·빌드 도구 없음) |
| 자세 인식 | MediaPipe Pose `0.5.1675469404` (CDN, 버전 고정) |
| 앱 설치·오프라인 | PWA: Web App Manifest + Service Worker |
| 음성 안내 | Web Speech API (`speechSynthesis`) |
| 저장 | `localStorage` |
| 배포 | GitHub Pages |

## 파일 구조

```
sololingo/
├── index.html        # 화면 구조 (HTML)
├── manifest.json     # 홈 화면 설치 정보 (이름, 아이콘, 테마색)
├── sw.js             # 서비스 워커: 앱 파일·AI 모델 캐시
├── css/
│   └── style.css     # 디자인
├── js/               # ⚠️ index.html에서 아래 순서대로 불러옴
│   ├── config.js     # 설정값: 운동 목록, 난이도별 세트·횟수, 배지, 식단, 인식 기준값
│   ├── storage.js    # 저장·불러오기, 날짜·연속 운동 일수 계산
│   ├── state.js      # 공용 상태 값 (XP, 레벨, 운동 진행, 카메라)
│   ├── utils.js      # 음성 안내, 진동, 알림, 화면 꺼짐 방지
│   ├── camera.js     # 카메라, MediaPipe 모델 준비·오류 복구
│   ├── counter.js    # 자세 판정: 각도 계산, 흔들림 보정, 운동별 횟수 세기
│   ├── workout.js    # 운동 창, 세트·휴식 진행, 단계 완료
│   ├── game.js       # XP·레벨, 퀘스트, 배지
│   ├── ui.js         # 코스·프로필·식단 화면, 탭 전환
│   ├── pwa.js        # 앱 설치 버튼, 서비스 워커 등록
│   └── main.js       # 앱 시작
└── icons/            # 앱 아이콘 (192, 512, maskable)
```

> 일반 `<script>`로 불러오기 때문에 파일끼리 함수와 변수를 공유합니다. 그래서 **불러오는 순서가 중요합니다.** 새 JS 파일을 추가하면 `index.html`의 `<script>` 목록과 `sw.js`의 `APP_FILES` 목록에 같이 넣어 주세요.

## 로컬에서 실행하기

카메라와 서비스 워커는 `https` 또는 `localhost`에서만 동작합니다. 파일을 더블클릭해서 열면 동작하지 않습니다.

```bash
git clone https://github.com/hvnwxu/sololingo.git
cd sololingo
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

> 파일을 고친 뒤에는 `sw.js`의 `CACHE_NAME` 버전(예: `sololingo-v4` → `v5`)을 올려야 설치된 앱에도 새 버전이 반영됩니다.
