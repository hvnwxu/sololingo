# SOLOLINGO 🦉 — AI 홈트레이닝

> 폰 카메라로 운동 자세를 인식해 **횟수를 자동으로 세어 주는** 홈트레이닝 웹앱
> 설치 없이 브라우저에서 바로 쓰고, 홈 화면에 추가하면 앱처럼 실행됩니다 (PWA).

**▶ 바로 사용하기: https://hvnwxu.github.io/sololingo/**

---

## 주요 기능

| 기능 | 설명 |
|---|---|
| 📷 AI 자세 인식 | 카메라 영상에서 관절 위치를 찾아 스쿼트·런지·푸쉬업 횟수와 플랭크 유지 시간을 자동으로 셉니다 |
| 🗺️ 단계형 코스 | 스쿼트 → 런지 → 푸쉬업 → 플랭크 → 버피테스트 순서로 하나씩 열리는 학습 경로 |
| 🎯 목표·난이도 | 다이어트 / 몸 만들기 / 바디프로필 × 초급 / 중급 / 고급에 따라 세트·횟수·휴식 시간이 달라짐 |
| ⏱️ 세트 & 휴식 | 세트가 끝나면 휴식 타이머가 자동으로 시작되고 음성으로 안내 |
| 🔊 2m 밖 안내 | 폰에서 떨어져도 알 수 있게: 시작 전 3·2·1 카운트다운, 화면 가운데 큰 횟수, 셀 때 효과음·초록 번쩍, 몸이 안 보이면 주황 테두리, 횟수·남은 개수·자세 교정을 음성으로 (🔊 전체 / 🔢 횟수만 / 🔇 끔) |
| ✅ 자세 분석 (스쿼트·런지·푸쉬업·플랭크) | 1회(플랭크는 1초)마다 깊이·상체 기울기·무릎 모임(런지)·몸 일직선(푸쉬업·플랭크, 처짐/들림 구분)을 규칙으로 판정해 화면과 음성으로 알려 주고(멘트는 돌아가며 바뀌고, 고치면 칭찬), 세트·운동이 끝나면 자세 리포트(좋은 자세 비율)를 보여 줍니다 |
| 📱 폰 위치 안내 | 운동별로 폰을 어디에, 어떤 방향으로 둬야 인식이 잘 되는지 그림으로 안내 |
| ⭐ 게임 요소 | XP·레벨, 일일 퀘스트, 업적 배지 5종, 연속 운동 일수 |
| 🥗 식단 가이드 | 운동 5개를 모두 끝내면 목표별 식단 예시가 열림 |
| 📋 기록 복사 | 운동 기록을 텍스트로 정리해 클립보드에 복사 (AI 인식 완료 / 수동 완료 구분) |

## 사용 방법

1. 폰 브라우저(크롬·사파리)에서 위 링크를 엽니다. 카메라 권한을 허용합니다.
2. 상단에서 **운동 목표**와 **난이도**를 고릅니다.
3. 열려 있는 단계(처음엔 ① 스쿼트)를 누르고, 안내에 따라 폰을 세운 뒤 **준비 완료! 시작하기**를 누릅니다.
4. 화면 안에서 운동하면 횟수가 자동으로 올라갑니다.
   인식이 어려운 환경이라면 **수동 완료**도 가능합니다 (AI 인식 완료와 별도로 기록).
5. 홈 화면에 추가하기: 안드로이드 크롬은 **📲 앱 설치** 버튼, 아이폰 사파리는 공유 → **홈 화면에 추가**.

## 동작 원리

```
카메라 영상 ──▶ MediaPipe Pose (관절 33개 좌표) ──▶ 각도·길이 계산 ──▶ 상태 판정(UP/DOWN) ──▶ 횟수 +1
```

- **관절 인식**: Google의 [MediaPipe Pose](https://developers.google.com/mediapipe) 모델이 프레임마다 어깨·팔꿈치·엉덩이·무릎·발목 등의 위치와 신뢰도(visibility)를 알려 줍니다.
- **더 잘 보이는 쪽 선택**: 왼쪽/오른쪽 관절의 신뢰도를 비교해 카메라에 더 잘 보이는 쪽 몸을 사용합니다.
- **운동별 판정**
  - **스쿼트·런지**: 엉덩이~무릎 세로 길이(허벅지)를 몸 크기로 나눈 비율을 씁니다. 서 있을 때 값과 비교해 앉았는지 판단하고, 발목이 보이면 무릎 각도(엉덩이-무릎-발목)도 함께 봅니다. 정면·측면 모두 인식됩니다.
    - **3D 좌표 사용**: MediaPipe가 함께 주는 미터 단위 3D 좌표(`poseWorldLandmarks`)로 허벅지 비율(= 허벅지 세로 길이 ÷ 실제 길이)을 계산합니다. 화면 좌표로 재면 정면에서 앉을 때 무릎이 카메라 쪽으로 나오면서 원근 때문에 허벅지가 길어 보여, 폰에 가까울수록(1.5m 이내) 깊이 앉아도 세지 않았습니다. 정면에서는 무릎 각도도 3D로 잽니다(화면상 무릎 각도는 앉아도 거의 안 줄어듦). 3D 좌표가 없을 때는 아래 화면 좌표 방식을 씁니다.
    - **몸 크기** = max(몸통 길이, 어깨 너비 ÷ 0.6). 매 프레임 새로 재므로 카메라에 다가가거나 물러나도 비율이 그대로입니다. 몸통 길이만 쓰면 정면에서 상체를 숙일 때 몸통이 짧아 보여 덜 앉은 것처럼 계산되는데, 어깨 너비는 숙여도 그대로라서 이를 막아 줍니다. 그래서 어깨부터 무릎까지 보여야 셉니다.
    - **스쿼트는 엉덩이가 실제로 내려가야** 셉니다. 완전히 서 있을 때의 엉덩이 높이보다 몸 크기의 0.2배(약 11cm) 넘게 내려가야 합니다. 상체를 숙이고 팔을 휘두르면 팔이 무릎을 가려 다리가 굽은 것처럼 잘못 잡힐 수 있는데, 이때 엉덩이 높이는 거의 그대로라 걸러집니다.
    - **스쿼트는 두 다리를 다 굽혀야** 셉니다 (덜 굽힌 다리 기준). 걷거나 발을 고쳐 디딜 때는 한쪽만 굽기 때문에 세지 않습니다. 런지는 반대로 더 굽힌 다리(앞다리) 기준입니다.
  - **푸쉬업**: 팔꿈치 각도(어깨-팔꿈치-손목)가 100° 아래로 내려갔다가 145° 위로 올라오면 1회.
  - **플랭크**: 어깨-엉덩이-무릎(발목)이 일직선인지 확인합니다. 1초 넘게 자세가 무너졌을 때만 타이머를 멈춰서, 잠깐 흔들린 건 봐줍니다.
- **흔들림 줄이기**: 한 프레임만 튀는 값에 속지 않도록 최근 값과 섞는 평균(지수 이동 평균)을 씁니다. 신뢰도 0.5 미만인 관절과 화면 밖(가장자리 3% 포함)에 있는 관절은 "안 보임"으로 처리합니다. 화면 밖 관절은 MediaPipe가 위치를 추측한 값이라, 신뢰도가 높게 나와도 믿지 않습니다.
- **너무 가까우면 세지 않기**: 몸이 화면에 너무 크게 보이면(약 1m 안) 스쿼트·런지를 세지 않고 "뒤로 물러나 주세요"라고 안내합니다. 가까이서는 원근 때문에 몸 비율이 크게 틀어져서, 폰을 보려고 숙이기만 해도 앉은 것처럼 계산되기 때문입니다.
- **두 번 세기 방지**: `UP → DOWN → UP` 순서를 거쳐야만 1회로 셉니다. 스쿼트·런지는 '앉음'이 0.15초 넘게 계속돼야 인정하고, 직전 횟수에서 0.7초 안에는 다시 세지 않습니다.
- **시작 카운트다운**: 시작 버튼을 누르고 폰에서 물러나는 동안은 세지 않습니다. 몸이 1초 동안 보이면 3·2·1 후에 세기 시작합니다.
- **자세 안내 음성**: 덜 앉았다 일어나면(스쿼트·런지) 또는 덜 내려갔다 올라오면(푸쉬업) 세지 않고 "조금 더 깊이"라고 알려 줍니다. 푸쉬업·플랭크에서 몸이 꺾이면 일직선으로 맞추라고 알려 줍니다. 같은 안내는 문제가 1.5초 넘게 계속될 때만, 5초에 한 번까지만 말합니다.
- **자세 분석 (룰 기반, 스쿼트·런지·푸쉬업·플랭크)**: 횟수와 별개로, 1회 동작 동안 값을 기록했다가 1회가 끝나면 규칙으로 판정합니다. 기준값은 `config.js`의 `FORM_RULES`에 모아 두었습니다.

  | 규칙 | 스쿼트 | 런지 | 확인 가능한 방향 |
  |---|---|---|---|
  | 깊이 부족 | 무릎 각도 ≥ 110° 이고 허벅지 비율 ≥ 0.5 | 무릎 각도 ≥ 105° 이고 허벅지 비율 ≥ 0.45 | 정면·옆 |
  | 상체 숙임 | 상체가 수직에서 50° 넘게 기욺 | 30° 넘게 기욺 (런지는 상체를 세운 채 내려가는 운동) | 옆모습만 |
  | 무릎 모임 | - | 앞 무릎이 엉덩이-발목 선에서 안쪽으로 엉덩이 너비의 0.5배 넘게 벗어남 | 정면만 |

  - **푸쉬업**: 1회 중 가장 작은 팔꿈치 각도가 90°보다 크면 "깊이 부족"(횟수는 100°부터 셈). 어깨-엉덩이-무릎(없으면 발목)이 180°에서 20° 넘게 꺾이면, 엉덩이가 바닥 쪽이면 "허리 처짐", 반대쪽이면 "엉덩이 들림". 바닥 쪽은 화면의 위아래가 아니라 **손목이 있는 쪽**으로 판단해서 폰을 어느 방향으로 눕혀도 동작합니다. 엉덩이·무릎이 안 보이면 일직선은 판정하지 않습니다.
  - **플랭크**: 1초마다 판정합니다. 어깨-엉덩이-발목(없으면 무릎)이 20° 넘게 꺾이면 처짐/들림을 음성으로 안내하고(타이머는 계속), 35° 넘게 꺾이면 타이머를 멈추고 처짐/들림에 맞게 안내합니다. 바닥 쪽은 손목, 안 보이면 팔꿈치가 있는 쪽으로 판단합니다(팔꿈치 플랭크는 팔꿈치가 바닥에 있음). 세트가 끝나면 "30초 중 좋은 자세 26초 · 허리 처짐 4초"처럼 요약합니다.
  - **깊이**는 무릎 각도와 허벅지 비율 중 하나만 기준을 넘어도 인정합니다. 정면에서는 엉덩이가 무릎 바로 위로 내려와 화면상 무릎 각도가 거의 줄지 않기 때문입니다.
  - **상체 숙임**은 정면에서는 숙여도 화면상 기울어 보이지 않으므로, 양쪽 어깨 사이가 몸통 길이에 비해 좁을 때(옆모습)만 판정합니다. **무릎 모임**은 반대로 정면에서만 보입니다.
  - **자세가 나빠도 횟수는 셉니다.** 판정이 틀렸을 때 운동한 횟수까지 잃지 않게 하기 위해서입니다.
  - **확실하지 않으면 지적하지 않습니다.** 관절이 3프레임 이상 보였을 때만 판정하고, 중간에 몸이 안 보인 1회는 판정하지 않습니다.
  - 화면에는 매회 결과를 보여 주고, 음성 지적은 같은 내용을 3회에 한 번만 말합니다.
  - 세트가 끝나면 휴식 화면에 "10회 중 좋은 자세 7회 · 깊이 부족 2회 · 상체 숙임 1회"처럼 요약하고, 운동을 마치면 자세 리포트를 보여 주며 기록에 저장합니다 (수동 완료는 저장하지 않음).
- **오류 대응**: 인식 중 오류가 나면 더 가벼운 모델로 바꿔 최대 3번 다시 시도합니다.

## 개인정보

- **카메라 영상은 폰 안에서만 처리되며 어디에도 전송되지 않습니다.** 서버가 없습니다.
- 운동 기록은 브라우저의 `localStorage`에만 저장됩니다. 그래서 다른 기기나 브라우저에서는 기록이 보이지 않습니다.

## 기술 스택

| 구분 | 사용 기술 |
|---|---|
| 화면 | HTML, CSS, JavaScript (프레임워크·빌드 도구 없음) |

| 앱 설치·오프라인 | PWA: Web App Manifest + Service Worker |

| 배포 | GitHub Pages |

## 파일 구조

```
sololingo/
├── index.html        # 화면 구조 (HTML)
├── manifest.json     # 홈 화면 설치 정보 (이름, 아이콘, 테마색)
├── sw.js             # 서비스 워커: 앱 파일·AI 모델 캐시
├── css/
│   └── style.css     # 디자인
├── js/
│   ├── theme.js      # 라이트/다크 모드 (<head>에서 먼저 불러옴)
│   │                 # ⚠️ 아래 파일들은 index.html 끝에서 이 순서대로 불러옴
│   ├── config.js     # 설정값: 운동 목록, 난이도별 세트·횟수, 배지, 식단, 인식 기준값
│   ├── storage.js    # 저장·불러오기, 날짜·연속 운동 일수 계산
│   ├── state.js      # 공용 상태 값 (XP, 레벨, 운동 진행, 카메라)
│   ├── utils.js      # 음성 안내, 진동, 알림, 화면 꺼짐 방지
│   ├── coach.js      # 2m 밖 안내: 소리 설정, 효과음, 자세 안내 음성, 시작 카운트다운, 큰 숫자 화면
│   ├── camera.js     # 카메라, MediaPipe 모델 준비·오류 복구
│   ├── counter.js    # 자세 판정: 각도 계산, 흔들림 보정, 운동별 횟수 세기, 1회(플랭크는 1초)별 자세 판정
│   ├── workout.js    # 운동 창, 세트·휴식 진행, 단계 완료
│   ├── game.js       # XP·레벨, 퀘스트, 배지
│   ├── ui.js         # 코스·프로필·식단 화면, 탭 전환
│   ├── pwa.js        # 앱 설치 버튼, 서비스 워커 등록
│   └── main.js       # 앱 시작
└── icons/            # 앱 아이콘 (192, 512, maskable)
```

> 일반 `<script>`로 불러오기 때문에 파일끼리 함수와 변수를 공유합니다. 그래서 **불러오는 순서가 중요합니다.** 새 JS 파일을 추가하면 `index.html`의 `<script>` 목록과 `sw.js`의 `APP_FILES` 목록에 같이 넣어 주세요.

## 로컬에서 실행하기

카메라와 서비스 워커는 `https` 또는 `localhost`에서만 동작합니다. 파일을 더블클릭해서 열면 동작하지 않습니다.

```bash
git clone https://github.com/hvnwxu/sololingo.git
cd sololingo
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```
